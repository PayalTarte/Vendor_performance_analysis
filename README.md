# Vendor_performance_analysis

## Project Overview

This project analyzes vendor purchasing and sales data to evaluate vendor performance, profitability, sales contribution, and purchasing efficiency.

## Objectives

- Analyze vendor sales and purchasing performance
- Calculate profit and profit margin
- Identify high-performing vendors
- Analyze sales contribution across vendors
- Generate business insights from the data

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Jupyter Notebook

## Analysis Performed

- Data loading and preparation
- Data cleaning and transformation
- Vendor-level sales and purchase analysis
- Profit and profit-margin analysis
- Inventory analysis
- Data visualization
- SQL-based vendor analysis
